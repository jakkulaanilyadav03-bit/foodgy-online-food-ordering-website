# Foodgy 🍔

A modern, responsive online food ordering website built with a premium dark-mode UI.

## Features
- **Beautiful UI**: Modern dark theme with smooth animations and interactive hover effects.
- **Dynamic Cart System**: Add items to your cart, adjust quantities, and calculate totals instantly.
- **Firebase Authentication**: Secure user login, sign-up, and password recovery via Firebase.
- **User Dashboard**: View order history and manage your profile once logged in.
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Firebase (Authentication & Firestore)

## How to Run Locally
1. Clone the repository.
2. Run a local development server (e.g., using Python: `python -m http.server 3000`).
3. Open `http://localhost:3000` in your web browser.
